# Google Maps, новий логотип і теми

У застосунку додано дорогу до українського прапора в логотипі та іконці вкладки. Кнопка із сонцем або місяцем у верхній панелі перемикає тему. Спочатку використовується тема пристрою; після натискання вибір зберігається в цьому браузері. Темна тема охоплює форми, картки та фон карти.

## Що дає Google Maps

Кнопка **«Місця в Google Maps»** відкриває пошук закладів, адрес і типів місць поблизу кінцевої точки маршруту. Картки Google показують доступні фотографії, години роботи та відомості про доступність. Знайдене місце в межах Києва можна обрати стартом або фінішем, а потім натиснути **«Побудувати маршрут»**.

Інтеграцію реалізовано через офіційний **Places UI Kit**, який Google дозволяє використовувати з картою Leaflet/OpenStreetMap. Картки та атрибуція відображаються компонентами Google. Дані завантажуються після натискання кнопки пошуку; зміна теми не створює нового пошуку.

Google доповнює відомості про місця. Маршрут та його оцінка продовжують використовувати OSM і доступні джерела застосунку. Google не підтверджує прохідність шляху, справність ліфтів чи відсутність бордюрів. Позначка доступного входу стосується закладу; її відсутність означає невідомий стан. Фото та картки Google не копіюються до бази перешкод і не завантажуються щоденним workflow.

## 1. Підготуйте ключ Google

1. Відкрийте [інструкцію Google для Places UI Kit](https://developers.google.com/maps/documentation/javascript/places-ui-kit/get-started). Створіть або оберіть власний проєкт Google Cloud і підключіть платіжний обліковий запис.
2. Увімкніть **Maps JavaScript API** та **Places UI Kit API**. Самого Places API (New) для цієї інтеграції недостатньо.
3. Створіть API key. У **Application restrictions** оберіть **Websites / HTTP referrers**. Для GitHub Pages додайте `https://YOUR_LOGIN.github.io/*`, замінивши `YOUR_LOGIN`. Для власного домену додайте його адресу, наприклад `https://example.com/*`.
4. У **API restrictions** дозвольте лише **Maps JavaScript API** та **Places UI Kit API**. Збережіть налаштування.
5. Перевірте квоти й тариф у Google Cloud. Запити можуть бути платними; підключення платіжного облікового запису не виконано за вас.

Для локального запуску окремо дозвольте `http://127.0.0.1:5173/*`; для локального перегляду Pages — `http://127.0.0.1:4173/*`. Якщо користуєтеся `localhost`, додайте відповідну адресу окремо. Обмеження за шляхом конкретного репозиторію можуть не спрацювати: браузер може надсилати Google лише домен у заголовку Referer.

Це **браузерний ключ**: після збірки він доступний у JavaScript сайту. Збереження в GitHub Actions Secret не приховує його від відвідувачів. Захист забезпечують обмеження доменів, API та квоти. Не використовуйте тут ключ від інших серверних сервісів.

## 2. Увімкніть пошук на GitHub Pages

1. Оновіть файли репозиторію з нового архіву, зберігши власні налаштування й папку `.git`. Надішліть зміни в `main`.
2. У репозиторії відкрийте **Settings → Secrets and variables → Actions → New repository secret**.
3. У полі **Name** введіть точно `VITE_GOOGLE_MAPS_API_KEY`, а в **Secret** вставте створений ключ.
4. Відкрийте **Actions → Deploy GitHub Pages → Run workflow** й запустіть публікацію з `main`.
5. Після успішної публікації відкрийте сайт, натисніть **«Місця в Google Maps»** і виконайте пошук, наприклад «Кафе».

Workflow вже передає цей параметр у статичну збірку. Зміна секрету без нової збірки не змінює опублікований сайт. Повна інструкція розгортання — [GITHUB_PAGES.md](GITHUB_PAGES.md).

## Локальний запуск

Скопіюйте `.env.example` у `.env` у корені проєкту. У PowerShell:

```powershell
Copy-Item .env.example .env
```

У macOS/Linux:

```bash
cp .env.example .env
```

Відкрийте `.env` у редакторі та заповніть рядок:

```dotenv
VITE_GOOGLE_MAPS_API_KEY=ВАШ_КЛЮЧ
```

Перезапустіть локальний сервіс або повторіть `npm run pages:build`. Файл `.env` виключений із Git; `.env.example` містить лише порожній приклад. Для запуску повної версії дивіться [README.md](README.md).

## Якщо дані не з’явилися

- **«Google Maps ще не підключено»**: ключ не потрапив до збірки. Перевірте точну назву секрету та повторіть workflow. Посилання «Переглянути місця в Google Maps» відкриває зовнішній сайт і саме по собі не підключає дані.
- **Помилка підключення**: перевірте обидва API, billing, квоти та дозволену адресу сайту. Після зміни обмежень Google може знадобитися час для їх застосування.
- **Пошук триває надто довго**: перевірте з’єднання чи блокувальник запитів і повторіть пошук.
- **Немає фото або позначки доступності**: Google може не мати цих відомостей. Застосунок їх не вигадує.
- **Місце поза покриттям**: картка доступна, але побудова маршруту поки обмежена адміністративними межами Києва (обидва береги).

Реальні запити до Google можна перевірити лише після підключення вашого ключа. До цього основна карта, геолокація, маршрути та обидві теми працюють без Google.

Офіційні джерела: [підключення UI Kit](https://developers.google.com/maps/documentation/javascript/places-ui-kit/get-started), [пошук місць](https://developers.google.com/maps/documentation/javascript/places-ui-kit/place-search), [захист ключів](https://developers.google.com/maps/api-security-best-practices), [умови Places UI Kit, розділ 15](https://cloud.google.com/maps-platform/terms/maps-service-terms).
