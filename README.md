# Доступний маршрут · Київ

Версія 0.3.0. Вебзастосунок українською для попереднього планування маршрутів: крісло колісне, дитячий візок, труднощі з ходьбою, прогулянка із собакою та велосипед.

## GitHub Pages

Додано окрему статичну збірку: `npm run pages:build`. Workflow `.github/workflows/pages.yml` сам збирає сайт для потрібної адреси, оновлює міські дані та публікує після push у `main`, вручну або щодня за розкладом.

На GitHub Pages доступні карта, геолокація й маршрути для всіх п’яти профілів. Спільні повідомлення, фото та підтвердження потребують окремого сервера і в цій збірці недоступні. Подальші розділи про D1/R2, спільноту й серверний кеш стосуються повної серверної версії; відмінності Pages описані в інструкції.

## Google Maps, логотип і теми

Новий SVG-логотип: плавна дорога веде до українського прапора. Повний знак для світлого й темного фону та окрема іконка лежать у `public/brand/`; текст переведено у векторні контури. Кнопка у верхній панелі перемикає світлу й темну теми та зберігає вибір у браузері.

Додано офіційний пошук Google Maps через Places UI Kit: картки місць із фото, годинами роботи й відомостями про доступність за наявності, вибір місця для початку або кінця маршруту. Для активації потрібен власний ключ Google Maps Platform; без нього основний застосунок працює, а панель чесно показує, що Google ще не підключено. Покрокова інструкція — **[GOOGLE_MAPS.md](GOOGLE_MAPS.md)**. Для GitHub Pages достатньо налаштувати ключ у Google, додати секрет `VITE_GOOGLE_MAPS_API_KEY` та повторити workflow.

Google доповнює відомості про місця; він не замінює граф OSM і не підтверджує прохідність маршруту. Картки завантажуються за запитом користувача. Інформація про приватність і умови доступна за посиланнями внизу застосунку.

## Запуск на комп’ютері

Потрібен Node.js 22.13 або новіший; рекомендовано Node.js 24 LTS. Розпакуйте архів і відкрийте термінал у папці, де лежить `package.json`.

Windows PowerShell:

```powershell
npm.cmd ci
npm.cmd run local:setup
npm.cmd run local:dev
```

macOS / Linux:

```bash
npm ci
npm run local:setup
npm run local:dev
```

Відкрийте http://127.0.0.1:5173. Для зупинки натисніть Ctrl+C. Геолокація запитується кнопкою «Моє розташування»; дозвольте її у браузері. На комп’ютері її точність залежить від пристрою. Для віддаленого використання геолокації потрібен HTTPS.

`local:setup` готує локальну SQLite-базу D1 і застосовує міграції. Попереднє виробниче збирання для локального запуску більше не потрібне. Фотографії, повідомлення й кеш міських даних зберігаються в `.wrangler/state`.

## Оновлення з попередньої версії

1. Зупиніть сервіс через Ctrl+C і збережіть копію попередньої папки проєкту.
2. Розпакуйте новий архів у ту саму папку із заміною файлів коду. Збережіть `.wrangler` — там локальні повідомлення, фотографії та голоси.
3. Виконайте три команди запуску вище. `local:setup` розпізнає базу першої версії й не створює таблиці повторно.
4. Оновіть вкладку браузера. Якщо зберігся старий інтерфейс, натисніть Ctrl+Shift+R.

Якщо розпакували архів в окрему папку, після зупинки сервісу перенесіть туди **всю** стару `.wrangler/state` перед `local:setup`. Папка `node_modules` встановлюється командою `npm ci`.

## Що додано

- Два нові профілі: «Із собакою» та «На велосипеді». Профіль змінює обмеження й ваги шляхів, а також вмикає відповідні шари карти.
- Пішохідна й велосипедна мережа всіх десяти районів Києва. Додано Дарницький, Дніпровський і Деснянський райони, а також зв’язки між берегами через придатні для профілю шляхи OSM. Адміністративні межі взято з OSM; передмістя не входять у покриття.
- Вбудований витяг OSM: 132 469 доріг і доріжок, 508 175 вузлів і 73 частини графа на обох берегах, стан бази 8 вересня 2026 року. Шляхи завантажуються частинами; не потрібні ключі API чи запити Overpass для кожного маршруту. Фон карти потребує інтернету.
- Офіційна веломережа міста, майданчики для собак, інфраструктура для тварин і громадські вбиральні. Початкові копії охоплюють обидва береги; кількість об’єктів і дати кожного джерела показані в застосунку. Числа змінюються після оновлення джерел; записи різних джерел можуть описувати те саме місце.
- Фільтри перешкод, туалетів, відпочинку й води, місць для собак, велоінфраструктури та парків. Кнопка огляду всього Києва та додаткові орієнтири в пошуку.
- Панель «Джерела й оновлення» показує походження, дату завантаження, дату оновлення джерелом і стан збереженої копії.

## Джерела й автоматичне оновлення

1. **OpenStreetMap / Geofabrik** — зв’язна мережа шляхів, обмеження, сходи, покриття, ухили, місця відпочинку, велопарковки тощо. Ліцензія ODbL: https://www.openstreetmap.org/copyright. Витяг: https://download.geofabrik.de/europe/ukraine.html.
2. **КМДА, велосипедна мережа** — GeoJSON API ІАС «Майно»: https://data.kyivcity.gov.ua/dataset/velosypedna-merezha-kyieva-dep-transport.
3. **КМДА, місця вигулу** — два CSV-ресурси, актуальні адреси яких автоматично знаходяться через каталог порталу: https://data.kyivcity.gov.ua/dataset/dani-pro-mistseznakhodzhennia-zon-dlia-vyhulu-domashnikh-tvaryn-dep-ecology. Місто вказує щорічне оновлення набору.
4. **ІАС «Майно», громадські вбиральні** — https://gisserver.kyivcity.gov.ua/mayno/rest/services/KYIV_API/WC/MapServer/0.
5. **Спільнота** — власні спостереження, фото й голоси. Їх завантажуємо перед кожною побудовою маршруту.

Міські джерела перевіряються при відкритті сторінки, кожні 30 хвилин у відкритій активній вкладці та кнопкою оновлення. Сервер повторно використовує останню успішну копію до 6 годин. Якщо API тимчасово недоступне, повертається остання успішна копія або копія з архіву з її справжньою датою й повідомленням про недоступність. Фонової роботи після закриття застосунку немає.

Міська веломережа відображається **окремим інформаційним шаром**. Вона не додає штучних з’єднань або дозволів до графа OSM. Сам маршрут обчислюється за зв’язками й обмеженнями OSM. Міські записи не є підтвердженням доступності для крісла колісного. Статус туалету подається як відомість джерела, а не поточна перевірка.

## Правила маршрутизації

Маршрути обчислюються у фоновому потоці браузера. Спочатку завантажується коридор між точками; якщо зв’язного шляху немає, перевіряється повна мережа Києва. Обмеження попередньої версії «до 15 км між точками» знято. Дві точки повинні бути в межах Києва, розташовуватися не ближче 25 м одна від одної та не далі 100 м від придатного для профілю шляху. Підходи до шляху показані пунктиром і не перевірені.

- Для крісла колісного виключаються нанесені сходи, високі бордюри, недостатня ширина, позначені ухили понад 8%, недоступні поверхні та ліфти з невідомим станом.
- Для собак враховуються позначені заборони вигулу та вимоги повідка на шляхах/вузлах. За побажанням надається перевага тихішим доріжкам. Правила парків можуть бути не нанесені на окремі доріжки, тому місцеві таблички потрібно перевіряти.
- Для велосипедів враховуються велосипедні заборони, односторонній рух і його велосипедні винятки. Велодоріжки й тихіші дороги мають перевагу. Сходи виключено. Пішохідні відрізки, де велосипед потрібно вести, окремо позначаються й отримують час пішого руху; їх можна вимкнути в додаткових побажаннях. Складні умовні заборони консервативно виключаються.
- Оцінки швидкості: 14 км/год для їзди велосипедом, 3 км/год для ведення велосипеда й неперевірених підходів; 2,7–3,5 км/год для пішохідних профілів. Це припущення, а не живий час руху.
- Коротший варіант зберігає базові обмеження профілю. Він вимикає додаткові побажання; дозвіл вести велосипед пішки зберігається.
- Повідомлення спільноти про перешкоди враховуються консервативно. Повідомлення про зміну стану не знімає перешкоду автоматично.

Відсутність позначок у джерелі не доводить прохідність або дозвіл на вигул. Застосунок може відмовити в побудові зв’язного маршруту. Це попереднє планування, без покрокової навігації та незалежного аудиту доступності.

## Обслуговування розробником

```bash
# Оновити копії міських даних, що постачаються з кодом
npm run data:refresh

# Перевірити алгоритм і реальні маршрути між районами
npm run test:routing

# Перевірити типи
npx tsc --noEmit
```

Для нового витягу OSM завантажте повний `ukraine-latest.osm.pbf` з Geofabrik (великий файл, близько 835 МБ на дату цієї версії). Потім:

```bash
python -m pip install osmium shapely
python scripts/import-kyiv.py /path/to/ukraine-latest.osm.pbf
```

Імпортер перевіряє всі десять районів, створює адміністративні межі, частини графа, орієнтири лівого берега та загальний набір корисних місць. Старі команди `import-right-bank.py` і `refresh-kyiv-snapshot.py` також викликають повний імпорт Києва. Користувачам цей імпорт для запуску не потрібен. Це ручна процедура обслуговування, без масового завантаження растрових тайлів. Після оновлення OSM повторіть імпорт міських копій і перевірки.

Технології: Vinext/React, Leaflet 1.9.4, Cloudflare D1 та R2. Виробниче збирання — `npx vinext build`; публікація керується Sites. API: `/api/reports`, `/api/vote`, `/api/photos/:id`, `/api/sources`.

Перевірено: типи, виробниче збирання, повноту посилань між частинами мережі, усі десять районів, обмеження профілів, напрямки велоруху, пішохідні відрізки велосипеда, CSV і реальні маршрути на обох берегах та між ними. Браузерне тестування й польову перевірку нової версії не виконано.
